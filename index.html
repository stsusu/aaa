AI 리터치 · PWA 설치 (선택)

이 기능은 웹 서버 주소로 접속할 때 사용합니다. 단일 HTML을 직접 열어도 일반 편집과 Potrace 변환은 동작합니다.

항상 적용되는 공통 기준 보기
  1. 이번 요청에 첨부된 이미지를 기준으로 쿠키커터·스탬프 제작용 선화로 정리합니다. 다른 도안의 특징이나 이전 도안의 수정사항을 가져오지 않습니다.
  2. 원본의 외곽 형태, 비율, 표정, 특징적인 선과 장식의 위치·개수를 보존합니다. 손그림의 개성을 유지하고 임의로 좌우 대칭을 강제하거나 형태를 재설계하지 않습니다.
  3. 흰 배경에 선명한 검은 선으로 정리합니다. 색상, 회색 음영, 그라데이션, 배경 잡음과 질감은 제거합니다.
  4. 떨리거나 울퉁불퉁한 선을 매끄럽고 연속적인 곡선으로 다듬고 선폭은 일관되게 정리합니다. 인접한 선이 불필요하게 붙거나 중요한 선이 사라지지 않도록 합니다.
  5. 디테일이 많은 부분은 쿠키커터·스탬프로 제작하기 쉽도록 간소화합니다. 촘촘한 잔선과 반복되는 작은 디테일을 줄이되, 원본을 알아보게 하는 특징과 주요 구조는 남깁니다.
  6. 원본에 없는 선·장식·얼굴 요소나 넓은 검정 채움 면을 임의로 추가하지 않습니다. 특정 부분의 제거·강조·형태 변경·채움은 아래 도안별 수정 요청에 명시된 경우 해당 부분에만 적용합니다.

개별 도안의 입·눈 등 수정 지시는 공통 기준에 포함하지 않습니다.

0 / 2,000자

비워 두면 공통 기준만 적용합니다. 새 이미지를 열면 요청을 비우고, AI 결과를 이어서 수정할 때는 유지합니다. 변경할 부분을 구체적으로 적어 주세요.

처음에는 원본, 이후에는 마지막 AI 참조 이미지를 전송합니다. 수동 편집한 획은 전송하지 않습니다. 결과는 새 레이어로 추가하고 이전 작업은 숨겨 보관합니다. 레이어 탭에서 다시 표시할 수 있습니다.

iPad: HTTPS 주소를 Safari로 열고 공유 → 홈 화면에 추가. PC: 브라우저의 앱 설치 메뉴.

그리기부터 제작까지

  1. 이미지를 열면 원본 참조·흑백 원본·드로잉 레이어가 생성됩니다.
  2. 레이어를 선택해 그리세요. 지우개는 현재 레이어만 지웁니다.
  3. 손가락은 이동, 두 손가락은 확대입니다. 펜 접촉 중 터치는 무시합니다.
  4. 도형은 선택 후 mm 속성을 변경하거나 캔버스에서 옮기세요.
  5. 프로젝트 파일을 저장하면 레이어와 편집 객체를 다시 열 수 있습니다.
  6. 제작·출력 → PNG → SVG 변환 → 커팅/스탬프/제외를 지정하세요.

단축키: B 펜, E 지우개, V 선택, L 올가미, H 이동, Ctrl/⌘ Z 실행 취소, Shift Z 다시 실행, Delete 선택 삭제.

자동 복구는 같은 브라우저·주소에 저장됩니다. 다른 기기에는 프로젝트 파일을 옮기세요. AI는 서버 연결이 필요하며 결과를 새 레이어로 보관합니다.

아이패드는 HTTPS 주소를 Safari로 열어 사용하세요. 필압·손바닥 차단은 기기 입력에 의존하므로 포함된 iPad 검사표로 확인하세요.
